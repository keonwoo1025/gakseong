# 각성

비각성자였던 주인공이 전설 직업을 계승해 100층 탑을 오르는 모바일 웹 액션 RPG.

## 실행

깃허브 페이지 같은 웹 주소에서 `index.html`을 연다. 파일을 직접 더블클릭해서 열면 데이터를 읽지 못한다.
컴퓨터에서 확인할 때는 이 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 접속한다.

## 구조

- `js/engine` 화면, 입력, 그림 불러오기
- `js/game` 게임 규칙 (주인공, 몬스터, 이펙트, 대사, 저장, 화면 정보)
- `data` 직업, 몬스터, 지도, 인물, 대사 (코드를 건드리지 않고 고칠 수 있는 부분)
- `assets` 그림 (교체 규칙은 ASSETS.md)

## 대사 작성 규칙

`data/dialogue/*.json`에서 `{이름}` `{성이름}` `{성}`을 쓰면 플레이어가 정한 이름이 들어가고,
`{이름:아}` `{이름:이}` `{이름:은}` `{이름:을}` `{이름:과}`처럼 쓰면 받침에 맞는 조사가 자동으로 붙는다.
줄에 `if`를 달면 성별, 직업, 플래그, 악업, 친밀도, NPC 성격에 따라 나오는 대사를 고를 수 있다.

## 지금 들어간 흐름

1. 캐릭터 생성 → 프롤로그 컷신(출근길, 공장 사무동, 포탈 사태와 탈출 조작, 민재, 옥상, 짐꾼 사무소)
2. 걸어 다니는 장소: 원룸, 거리, 짐꾼 사무소, 편의점, 헌터 상점(각성 후), 탑 입구 광장
3. 오른쪽 탭으로 말 걸기·조사·줍기, 메뉴에서 가방·상태·저장·설정
4. 짐꾼 생활: 사장님에게 의뢰 → 광장에서 들꽃 파티와 출발 → 파티가 싸우는 동안 따라다니며 마정석 줍기, 구급상자 건네기, 회피 → 일당 → 원룸에서 잠 (생활비 차감)
5. 9층까지 동행하면 다음 원정에서 10층 균열 → 신의 시험 → 행동 패턴으로 전설 직업 계승, 이때부터 레벨과 경험치 시작
6. 각성 후: 광장의 탑 입구에서 정체를 숨긴 채 층 돌파 (목표 처치 → 보스), 소문과 뉴스 변화
7. 31층 기한이 흐르고, 죽으면 기록이 지워짐

## 조작 (기본)

- 왼쪽 아래 조이스틱으로 이동 (끝까지 밀면 달리기). 손가락이 밖으로 나가도 떼기 전까지 방향 유지
- 오른쪽 큰 버튼: 마을과 탑에서 공격 (달리며 누르면 돌진 베기), 원정에서는 줍기·건네기
- 말 걸기·조사: 마을에서 대상 근처면 공격 버튼이 말 걸기·조사로 바뀐다
- 마을 PK: 오른쪽 위 PK 버튼으로 켜고 끔(기본 끔, 켜면 빨간 테두리). 켜면 마을 사람도 공격 대상, 성격에 따라 반격·도망·애원·신고. 이름 있는 인물은 기절, 행인은 죽으면 다른 구역에 새 행인
- 회피, 기술, 회복 버튼. 빈 곳을 밀어도 회피
- 메뉴: 가방, 장비, 상태, 지도, 퀘스트, 설정 (조이스틱 방식, 민감도, 버튼 크기, 왼손 모드, 화면 확대)
- 도시는 구역이 길로 이어져 있고, 가장자리로 걸어가면 옆 구역으로 넘어간다. 오른쪽 위에 미니맵

## 장소와 컷신 고치기

- 장소: `data/town/*.json` (글자 지도, 문, NPC, 조사할 물건, 트리거)
- 컷신: `data/cutscenes/*.json` (이동, 대사, 선택지, 연출 명령)
- 사람 외형(임시 도트): `data/looks.json`

## 그림 업데이트

새 그림 파일을 받으면 같은 경로에 덮어쓰고, `data/manifest.json`의 `version` 숫자를 올리면 폰에서도 새 그림을 바로 불러온다.
그림이 없는 자리는 분홍색 임시 상자로 표시된다.

## 조작

- 왼쪽을 끌어 이동, 끝까지 밀면 달리기
- 오른쪽 탭은 공격(연속으로 탭하면 3단 콤보), 오른쪽을 밀면 그 방향으로 회피
- 키보드: WASD 이동, Shift 달리기, J 공격, K 회피

## 장비 (data/items.json, data/gear.json)

- 부위: 무기·옷·가면(보이는 장비), 신발·반지·목걸이(능력치만). 각성 전에는 옷만
- 무기 7종(검·도·창·활·지팡이·단검·건틀릿)마다 콤보 사거리·속도·위력이 다르고, 전설·신화 무기는 콤보 1단계 추가
- 희귀도 6단계, 강화 +15(+8부터 실패 시 1단계 하락, 파괴 없음), 숙련도 10단계
- 무기·가면 그림 자리: weapons 아틀라스에 `w_아이템id`(또는 `w_무기종류`), `m_아이템id` 이름으로 넣으면 자동 교체

## 마을 맵 형식 (data/town/*.json)

- `ground` + `legend`: 바닥 글자 지도 (길·풀·벽·문 등)
- `props`: 오브젝트 목록 `{obj, at}`. 종류는 data/objects.json 에서 재사용 (이름·충돌·그림)
- 충돌: 0 통행, 1 막힘, 2 물, 3 낮은 막힘. 오브젝트·바닥에서 자동 계산, 필요하면 `collision` 글자 지도(0~3)로 덮어쓰기
- `items`: 놓인 아이템 `{id, at, n, key}`. 한 번 주우면 key로 기록되어 다시 안 생김
- `doors`·`edges`: 문과 가장자리 이동, `npcs`: 배치 NPC, `events`: 밟으면 실행되는 컷신, `objects`: 조사 지점

## 이벤트 (data/events.json, data/events/*.json, 맵의 events)

- 이벤트 = 트리거(on) + 조건(if) + 행동(play 또는 steps). once 기본 true
- 트리거: step(밟기 rect), talk(npc), examine(조사 지점 id), enter(맵), item(아이템), kill(처치 수 count, monster), day·flag(조건만)
- 조건: flag, noflag, gender, phase, job, awakened, var, day, karma, aff, item, lv, quest, all·any·not
- 행동: 기존 컷신 명령(say·move·face·spawn·cam·fade·card·map·fight 등) + label·goto(if 붙이면 조건 분기), camMove·zoom·camReset, quest(act: start·done), var(set·add), give, money, aff, karma, sys(시스템창), event(다른 이벤트 이어 붙이기)
- 선택지 분기: 선택지에 flag 를 달고 다음 줄에 {goto, if:{flag}}

## 퀘스트 (data/quests.json)

- 메인·서브, 단계별 목표(kill·collect·talk·go·floor), 보상(money·exp·items·aff), 기한(deadline)
- 머리 위 표시: 받을 수 있으면 ?, 보고할 수 있으면 !. 각성 전에는 퀘스트 없음(지금 할 일 안내만)
- 퀘스트 창에서 고른 퀘스트를 목표 화살표가 안내

## 직업·NPC 틀

- 기본 직업 6종(data/jobs.json, basic): 검사·전사·궁수·마법사·성직자·도적. NPC 전용, 기술 3개(3번째는 C급 이상). 히든 직업은 `_히든` 자리만
- 등급(F~S)은 능력치(data/folk.json ranks), 직업은 싸우는 방식·사거리·기술·무기. 들꽃 파티 역할도 직업 데이터에서 읽음
- 성격 10유형(data/personality.json): 성향 5축 axes[선악, 대담, 사교, 이성, 질서], 좋아하는 선물 likes, 기본 말투 speech, 대사 lines(stranger, known[존댓말, 반말] 등)
- 친밀도 0~100(data/affinity.json 단계): 하루 한 번 대화 +2, 선물(하루 한 번) +8/+3/-2, 원정 동행 +2, 공격 -15. 선한 성향은 악업 20 이상이면 멀어짐. 친구 이상 + 질서 성향 낮으면 반말로
- 시간대: 아침·낮·저녁·밤. 탑에서 돌아오면 한 단계, 자거나 원정 후엔 아침. 맵 NPC는 hours, 행인은 schedule로 시간대별 등장
- 행인 파츠: 머리 8종, 옷 6종(outfit), 안경. 역할 행인·헌터(광장에서 탑으로 들어감)·상인·경비
- 신고 누적(악명 3 이상)이면 바깥 구역에서 협회 경비대 출동: 순순히 따르면 벌금, 저항하면 전투(PK 자동 켜짐). 악명 5 이상이면 상점 거래 거부. 하루 지나면 악명 -0.5

## 2차 편의·전투

- 저장: 시스템 탭에서 어디서든. 탑 안에서 저장하면 이어할 때 그 층 처음부터. 구역 이동·층 돌파 때 자동 저장
- 조작 편집: 버튼·조이스틱을 끌어서 옮기고, 누른 것은 아래 막대로 크기 조절 (Settings btnPos·btnScale·joyPos·joyScale)
- 스킬 트리: 액티브·패시브 줄, 앞 단계를 배워야 다음 단계. 배운 액티브는 버튼 칸 1~4 중 원하는 곳에 배치(slotMap)
- 무기 효과(data/gear.json effects): 검 치명타, 도 출혈, 창 관통, 활 꿰뚫음, 지팡이 폭발, 단검 배후·연타, 건틀릿 기절. 영웅 이상은 고유 옵션 1개(opts)
- 소모품: 강화제(공격·방어·이동 60초), 해독제, 마력 물약, 엘릭서, 귀환석(탑 안 → 광장). 가방에서 '빠른 사용 지정'
- 드롭: 탑에서 아이템이 바닥에 떨어지고, 근처에 적이 없으면 공격 버튼이 '줍기'로 바뀜. 등급 색 빛기둥·이름표
- 10층: 이레귤러가 들꽃 파티를 쓰러뜨리는 컷신 → 균열·시험·각성 → 10층으로 돌아와 이레귤러와 싸움 → 1~10층 돌파 처리, 11층부터

## 3차-1 탑 미로·보스방·AI

- 일반 층(js/game/maze.js): 방 12개(짐꾼 원정 6개)를 통로로 이은 미로. 바이옴 벽, 높은 방 아래 절벽·계단, 시작에서 가장 먼 방이 보스방, 막다른 방에 보물 상자
- 층 돌파 = 보스방을 찾아 보스 처치. 들어가면 문이 닫힘. 미니맵은 가 본 곳만
- 몬스터 2.5배, 죽으면 18초 뒤 플레이어에게서 먼 곳에 다시 생김. 옆으로 돌아 들어오기, 둘까지만 동시에 공격(나머지는 주위를 돎), 체력이 적으면 잠깐 후퇴
- 다른 헌터 파티(js/game/allies.js): 절반 확률로 층에 NPC 파티 3명. 직업대로 싸우며, 마지막 일격이 NPC면 보상 없음
- 일반 NPC 초상화: 남녀별 3개 돌려쓰기(looks npc_m1~3·npc_f1~3, port2 그림이 오면 자동 교체). NPC 공격 모션(준비·내딛기·휘두르기)

## 이펙트·모션 (assets/atlas/fx3.png)

- 평타: 무기 종류별(atk_sword·blade·spear·dagger·punch), 활은 화살이 날아가 맞으면 arrow_hit, 지팡이는 마력탄(bolt)
- 타격 hit·치명타 crit·패링 parry·빗나감 miss·방어 무시 armorbreak·처치 defeat·구르기 먼지 rolldust, 속성 el_*(8종)
- 스킬: skills.json 의 fx 이름(geomgang 등)과 같은 그림이 자동 연결. 직업별 회피 이펙트 dodge_*
- 상태 아이콘 st_*: 적 머리 위(출혈·화상·둔화·기절)
- 모션은 코드로: 무기 종류별 몸 기울이기·내딛기·반동과 무기 궤적, 구르기는 몸을 회전. 그림 모션은 캐릭터 디자인 때 한 화풍으로 받기

## 메뉴·지도·퀘스트 화면 개편

- 왼쪽 위 버튼: 메뉴(마지막 탭 기억) / 지도 전용 화면(한성특별시 ↔ 대한민국, 끌어서 이동·확대) / 퀘스트 패널(게임 화면 옆, 다시 누르면 닫힘)
- 창을 연 직후 0.45초 클릭 무시(손을 뗄 때 다른 탭이 눌리던 문제), 창 바깥을 누르면 닫힘
- 메뉴 탭: 상태·인벤토리·스킬·퀘스트·시스템, 찍을 포인트·새 아이템이 있으면 빨간 점
- 인벤토리: 착용 칸 + 분류(전체·무기·방어구·소모품·재료)·정렬(등급·최근) + 착용 장비와 능력치 비교(▲▼), 두 번 누르면 장착·사용
- 스탯 +는 길게 누르면 연속, 추천 분배. 스킬 +는 길게 누르면 가능한 만큼
- 전설직별 무기 종류(gear.json jobWeapons): 천마 검·도, 폭풍의 사수 활, 대지의 군주 건틀릿·창, 공간의 절대자·성휘의 사도 지팡이, 명왕 단검. 각성 때 맞는 무기가 없으면 기본 무기 지급
- 전국 지도 그림은 ui 아틀라스 koreamap 이름으로 넣으면 교체
