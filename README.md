# 각성

비각성자였던 주인공이 전설 직업을 계승해 100층 탑을 오르는 모바일 웹 액션 RPG.

## 실행

깃허브 페이지 같은 웹 주소에서 `index.html`을 연다. 파일을 직접 더블클릭해서 열면 데이터를 읽지 못한다.
컴퓨터에서 확인할 때는 이 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 접속한다.

## 구조

- `js/engine` 화면, 입력, 그림 불러오기
- `js/game` 게임 규칙 (주인공, 몬스터, 이펙트, 대사, 저장, 화면 정보)
- `data` 직업, 몬스터, 지도, 인물, 대사 (코드를 건드리지 않고 고칠 수 있는 부분)
- `assets` 그림 (교체 규칙은 ASSETS.md)

## 대사 작성 규칙

`data/dialogue/*.json`에서 `{이름}` `{성이름}` `{성}`을 쓰면 플레이어가 정한 이름이 들어가고,
`{이름:아}` `{이름:이}` `{이름:은}` `{이름:을}` `{이름:과}`처럼 쓰면 받침에 맞는 조사가 자동으로 붙는다.
줄에 `if`를 달면 성별, 직업, 플래그, 악업, 친밀도, NPC 성격에 따라 나오는 대사를 고를 수 있다.

## 지금 들어간 흐름 (1부 뼈대)

1. 캐릭터 생성 → 프롤로그(공장 포탈, 민재, 퇴사, 짐꾼 사무소) 대사와 선택지가 행동 패턴으로 기록됨
2. 도시: 사무소(뉴스, 짐꾼들과 대화, 성격별 대사), 상점, 장비와 스탯, 탑, 집(휴식, 저장)
3. 짐꾼 시절: 1~9층 의뢰를 마치면 10층 들꽃 파티 동행 의뢰가 열림
4. 10층 균열과 신의 시험 → 행동 패턴으로 전설 직업 계승, 스탯 재분배
5. 각성 후: 정체를 숨긴 채 층을 돌파 (목표 처치 → 보스). 최초 돌파와 처치가 소문 수치를 올리고, 소문에 따라 뉴스가 바뀜
6. 31층 기한 D-day가 흐르고, 죽으면 기록이 지워짐

## 그림 업데이트

새 그림 파일을 받으면 같은 경로에 덮어쓰고, `data/manifest.json`의 `version` 숫자를 올리면 폰에서도 새 그림을 바로 불러온다.
그림이 없는 자리는 분홍색 임시 상자로 표시된다.

## 조작

- 왼쪽을 끌어 이동, 끝까지 밀면 달리기
- 오른쪽 탭은 공격(연속으로 탭하면 3단 콤보), 오른쪽을 밀면 그 방향으로 회피
- 키보드: WASD 이동, Shift 달리기, J 공격, K 회피
